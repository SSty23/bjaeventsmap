About UK Judo Events Map

This website is an independent event-discovery tool designed to make it quicker and easier for judoka to find nearby and online judo events across the UK.

Event information is collected from publicly available listings published by judo organisations and reorganised into a searchable map and event list.

This website is not affiliated with, endorsed by, or operated by British Judo or any other judo organisation.

This website is not an authoritative source of event information. Event details can change or may be incomplete. Always check the organiser's official event page for the latest dates, venue details, eligibility requirements and entry information before travelling or entering.
